三步接入

  1. 引入字体与令牌。先字体后令牌，放在业务样式之前。

    HTML
    <link rel="stylesheet" href="fonts/fonts.css">
<link rel="stylesheet" href="tokens/theme.css">

  2. 选主题。主题只由根元素的 data-theme 决定；不设则跟随系统。运行时切换只改这个属性。

    <html data-theme="light">   <!-- 固定明亮 -->
<html data-theme="dark">    <!-- 固定深色 -->
<html>                      <!-- 跟随系统 -->

document.documentElement.dataset.theme = 'dark';   // 运行时切换

  3. 把硬编码的值换成令牌。组件 CSS 只写一份，深色模式全靠令牌切换，不要写 .dark 分支。

    .panel        { background: var(--card); border: 1px solid var(--border-subtle);
                border-radius: var(--r-xl); padding: 24px; }
.panel__title { color: var(--heading); }
.panel__desc  { color: var(--body-subtle); }
.panel a      { color: var(--fg-brand); }

浏览器要求 Chrome / Edge 119 及以上：模版用到 color-mix() 与相对颜色语法（--elevation-3）。Safari、Firefox 未在本项目中验证。

设计原则

蓝色只给操作和选中主按钮、链接、激活导航、选中标签页、开关开启、图表主系列。不要用品牌蓝铺大面积底色。
状态色只表示状态模版原话：状态色表示状态，绝不用于装饰。仿真场景建议：完成、收敛用 success；发散、报错、中止用 danger；超限、待确认用 warning；运行中、提示用 info（即品牌蓝族）。
主操作与危险操作不同色品牌蓝与 danger 在色相环上相距 {{DANGER_GAP}}。原品牌珊瑚红与 danger 只差 {{CORAL_GAP}}，「运行」与「报错」几乎同色，这是换色的直接原因。
一切取值走令牌颜色、圆角、阴影、字体都用 var(--…)。业务代码里不新增 hex。
中性色是暖石灰标题墨色带极轻的暖调。不要混入纯灰或冷灰（如 Tailwind 的 gray、slate 一类）。
深色不是反相面、线按明亮版的明度关系推出；文字在它所在的每一种底色上都不低于明亮版。品牌文字色是唯一约定的例外（见对比度）。

{{COLOR_TABLES}}

信息族已并入品牌色阶（IBM Carbon 的做法）：--info 等于 --brand，--info-strong 等于 --fg-brand-strong，--info-soft 等于 --brand-softer。用 info 令牌写的「信息 / 运行中」提示与品牌色一致。

图表配色按模版：主系列 --brand，对比或上期 --series-soft，第二系列 --teal，第三系列 --purple。品牌蓝与紫的色差比原站小（见已知问题），三个系列以上时配合图例和线型区分，不要只靠颜色。

对比度

APCA Lc 是 W3C 下一代对比度草案的读数，绝对值越大越清楚。常用读法：正文 75 以上，其他内容文字 60 以上，标题与大字 45 以上，禁用与占位 30 以上。WCAG 2 一列供熟悉旧标准的同学对照（AA：正文 4.5:1，大字 3:1）。

{{CONTRAST_TABLE}}

深色版的品牌文字有意降低对比换取彩度（Lc {{FG_LC}}，依据是 Helmholtz–Kohlrausch 效应：高彩度文字看起来比亮度更亮）。它为短链接、导航标签而定；成段正文不要用品牌色。

组件规格

每类组件的实际效果见本页末尾的 组件样例（模版组件页原样搬入，可交互）。业务页的同类组件按下面的要点对齐，完整 CSS 见每组的摘录（模版原文）。

组件要点
按钮胶囊形（--r-full），14px / 500，内边距 14×26；小号 12×20，大号 17×24、16px。主按钮是竖向渐变 brand-light → brand → brand-medium，1px brand-light 描边，白字，悬停时渐变下移露出深端。次要按钮：card 面、border 描边、heading 字；描边按钮透明底；幽灵按钮无边框。焦点 = elevation-1 叠加 focus-ring。
输入框card 面、1px border、--r-md，内边距 12×14，14px；占位符 body-subtle。聚焦：品牌色描边 + focus-ring；出错：danger-strong 描边；禁用：50% 不透明。
徽章、提示条浅底（-soft）+ 深字（-strong / fg-warning）+ 描边（浅底与文字色 8:2 混合）。徽章 12px / 500、内边距 3×9；提示条 14px、内边距 16、--r-md。
标签页胶囊式：选中为品牌底白字，悬停 hover-fill。下划线式：选中为 fg-brand 字 + 2px 品牌色底线。
开关、复选、单选开关轨道 40×22，关为 body-subtle，开为 brand；滑块白色 18px。复选、单选用 accent-color: var(--brand)。
卡片、表格卡片：card-soft 底、border-subtle、--r-xl、内边距 24。表格：card 底、border 外框、--r-xl；表头 12px 大写、字距 .04em、body-subtle；单元格 14px、body、行线 border-subtle、内边距 12×16。
菜单、下拉card 面、border、--r-lg、elevation-2、内边距 8；菜单项 14px / 500、--r-md；激活项 brand-softer 底 + fg-brand-strong 字。
弹窗、抽屉、提示弹窗：card 面、border、--r-xl、宽 440、内边距 24。抽屉：右侧 360 宽、左边框。遮罩用 --scrim。工具提示：--tooltip 底、白字、13px、--r-md。

深色模式

  • 只换令牌。组件 CSS 一份，切 data-theme 即可。业务页不要写深色特例。
  • 抬升靠高光，不靠黑影。深色的 --elevation-1/2 带 1px 白色顶缘高光；黑影叠在黑底上看不见。
  • 遮罩统一 70% 黑（--scrim：明亮 {{SCRIM_LIGHT}}，深色 {{SCRIM_DARK}}）。
  • 位图压暗，不改资产。深色下给照片、截图加 filter: brightness(.92) saturate(.96)。
  • 文字在每一种底色上都不低于明亮版。深色卡片比页面底亮，只在页面底上调对比会让卡片上的字变暗；模版的文字令牌已按「所在的每种底色都不退化」推出，业务页直接用令牌即可。
  • 基色当文字时换前景档。品牌基色、危险基色是给按钮面和图形用的；拿来写字时，品牌字用 --fg-brand，危险字用 --danger-strong。
  • 插画只暗化纸面与结构。白底、浅灰面、描边跟主题变，插画里的彩色图形不动；插画里的文字（含头像缩写）按文字处理，用文字令牌或按所在底色重新取色。
  • 工具提示用 --tooltip。不要用标题色当气泡底：标题色在深色下翻成近白，白字会看不见。
  • 图表次要系列换专用值。深色的 --brand-soft 与卡片同明度，画成线会消失，改用 --series-soft。面积渐变顶部的不透明度按 4/3 补偿：{{OPACITY}}。
  • 悬停底用 --hover-fill。

改造现有页面

  1. 盘点颜色字面值。先知道要换多少处。

    grep -rnoE '#[0-9a-fA-F]{3,8}\b|rgba?\([^)]*\)' src/ | cut -d: -f3- | sort | uniq -c | sort -rn

  2. 按用途换成令牌，见下表。同一个颜色值在不同位置可能对应不同令牌，按用途判断，不要按值批量替换。

  3. 先全局，后组件。页面底、文字、标题、边框、圆角、字体 → 按钮 → 表单 → 卡片与表格 → 菜单与浮层 → 图表。每类组件在 Components 页找对应样例，核对内边距、圆角、字号。

  4. 用了组件库时改主题变量。把组件库的主色、圆角、字体等主题变量指向这些令牌，不要逐个覆盖组件样式；组件库自动生成的浅色阶要逐项核对。

  5. 两个主题都过一遍。切换 data-theme 逐页检查。深色有问题只在令牌层修。

验收清单

  • 业务样式里没有新增的 hex / rgb 字面值（令牌文件除外）。
  • 每页在明亮、深色两个主题下都检查过，没有深底深字或浅底浅字。
  • 一个视图里只有一个主按钮；删除、中止等危险操作用 danger 色。
  • 状态色只出现在状态位置：徽章、提示条、状态点、表单校验。
  • 键盘 Tab 时能看到焦点环。
  • 数字列、时间戳、代码用等宽字体或 tabular-nums。
  • 文字对比度不低于对比度表里同场景的值。
  • 字体确实加载：DevTools 控制台执行 document.fonts.check('16px "Noto Sans SC"') 返回 true。
  • 图表三个系列以上时有图例或线型区分。

已知问题

  • 品牌文字色是深色对比度的唯一约定例外。深色下拿对比度换彩度（见对比度一节）；成段正文不要用品牌色。
  • 品牌蓝与图表紫的色差为 {{PURPLE_DE}}（OKLab ΔE），原站三个系列两两为 {{ORIG_DE}}。系列多时配合图例与线型。
  • 深色 --fg-brand-strong 的彩度已到 sRGB 上限，无法更艳。
  • 信息族并入了品牌色阶，与旧版独立的 info 蓝不同。
  • 明亮模版的四处遮罩取值不一，--scrim 取弹窗那一档。

维护

包内文件都由脚本生成，不要手改。改颜色回到构建管线：品牌色在 _theme_brand.py（ANCHOR 当前为 {{ANCHOR}}），中性色与状态色的深色值在 _theme_dark.py。改完按顺序重新生成：

python3 _build_zh.py --sim
python3 _build_zh.py --sim --dark
python3 _pack_sim.py
